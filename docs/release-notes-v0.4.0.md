# ALT Foundry Kernel v0.4.0 Release Notes Draft

Paper DOI: [https://doi.org/10.5281/zenodo.20476200](https://doi.org/10.5281/zenodo.20476200)

Release title:

`ALT Foundry Kernel v0.4.0: Language-Neutral Abstraction Liquidity Theory Reference Kernel, Estimators, Certificates, and Conformance Fixtures`

v0.4.0 turns ALT Foundry Kernel into a v1.0.0-equivalent public reference
surface for Abstraction Liquidity Theory. ALT asks when local traces become
reusable abstraction capital. The answer is not compression, novelty, benchmark
transfer, trace volume, or library growth by itself. A trace-derived object must
become an abstraction token, carry executable certificate packets, pass
measurement and transport checks, respect hazard and authority envelopes, and
settle only when conservative signed surplus is positive.

## Highlights

- Adds deterministic estimator helpers for finite-sample evidence, proxy
  bridges, causal modes, transport diagnostics, guard risk, federated pooling,
  portfolio selection, foundry phase control, reproduction phase, CARA
  time-to-target, and alpha-budget gates.
- Adds schemas and examples for estimator artifacts and release manifests.
- Adds v0.4.0 conformance fixtures for no trace sufficiency, no off-policy
  overlap, invalid proxy bridge, high-dimensional transport failure,
  PoUA-as-authority failure, unidentified recombination, guard calibration
  failure, unsafe CARA target timing, and exhausted evidence budget.
- Expands docs and AGENTS.md for autonomous and non-Python implementers.
- Preserves fail-closed semantics: missing capital-relevant evidence is
  undefined, not zero.

## Scientific Limits

The release computes generic certificates from declared data. It does not infer
real-world causal identification, transportability, root authority,
recombination structure, or ASI target realization without explicit evidence.
